# codealpha_Basic-chatbot
Basic Chatbot using Python – A simple rule-based chatbot that interacts with users and responds to greetings, questions, and common messages.
Basic Chatbot Using Python

Project Description

The Basic Chatbot is a simple Python-based project that interacts with users through text messages. It uses predefined rules and conditions to understand user inputs and provide suitable responses.

Features

Responds to Hello, Hi, and Hey.

Answers "How are you?"

Introduces its name.

Provides help information.

Responds to Thank You.

Ends the conversation when the user types Bye or Exit.

Technologies Used

Python 3

Conditional Statements

While Loop

Functions

String Handling

How to Run

Install Python 3.

Download or clone this repository.

Open the project folder.

Run the following command:

python basic_chatbot.py

Example Output

User: Hello

Chatbot: Hello! How can I help you?

User: How are you?

Chatbot: I am fine, thank you!

User: Bye

Chatbot: Goodbye! Have a nice day!
